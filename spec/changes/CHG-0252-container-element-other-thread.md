## What changed for programs

A program in which one thread ends a container element — by `pop`, `replace`, `take_raw`, growing the
container, a priority queue's `pop` — while another running thread holds an exclusive reference to that
element now faults `diag.aliasing-conflict` in the first thread, where it raced before. One-thread programs are
unchanged.
